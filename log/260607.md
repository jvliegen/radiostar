# CeeBee

Before continuing on the sending side, maybe it's more "trustworthy" to begin on the receiver side.
As I have already a +- 27 oscillator ready, I could start with a CB receiver.

[https://www.youtube.com/watch?v=S1heLSx9GFs&t=745s](This) youtube clip says that every basic analog receiver needs these four components:

* a Band pass filter
* a mixer
* an oscillator
* an amplifier

> Homebrewing wisdom advises building backwards!

1. audio amp
2. mixer (product detector)
3. oscillator
4. band pass filter
